# Landing Page Structure Report

## Enfoque General

Para una landing premium de arquitectura, conviene pensar la experiencia como una narrativa visual de una sola pagina antes que como una web con muchas paginas tradicionales.

La estructura debe guiar al usuario desde una primera impresion estetica fuerte, hacia confianza profesional y finalmente contacto.

## Estructura Recomendada

### 1. Hero

Objetivo: generar impacto visual inmediato.

Contenido recomendado:

- Imagen o experiencia visual principal.
- Nombre o concepto fuerte del estudio.
- Frase breve de posicionamiento.
- CTA principal: `View projects`, `Explore studio` o `Start a project`.
- En desktop puede ser inmersivo; en mobile debe priorizar claridad y buena composicion.

### 2. Studio Intro

Objetivo: explicar la vision del estudio.

Contenido recomendado:

- Statement editorial corto.
- Texto breve sobre enfoque arquitectonico.
- Tres conceptos clave: materialidad, luz, proporcion, paisaje o detalle.
- Diseno limpio, con aire, buena tipografia y jerarquia clara.

### 3. Featured Projects

Objetivo: mostrar calidad real de trabajo.

Contenido recomendado:

- Tres a seis proyectos destacados.
- Imagen principal por proyecto.
- Nombre del proyecto.
- Tipo de proyecto: residencial, interior, conceptual, hospitality.
- Ubicacion y ano si aplica.
- CTA a detalle o `View project`.

Esta es una de las secciones mas importantes para una landing de arquitectura.

### 4. Project Detail / Case Study

Si mas adelante se agregan paginas internas, cada proyecto deberia tener su propia pagina.

Contenido recomendado:

- Hero visual del proyecto.
- Descripcion conceptual.
- Galeria.
- Datos tecnicos.
- Proceso o narrativa de diseno.
- Materiales.
- Resultado final.

### 5. Services / Expertise

Objetivo: explicar que ofrece el estudio.

Contenido recomendado:

- Architecture design.
- Interior architecture.
- Concept development.
- Spatial identity.
- Visualization / 3D.
- Project consulting.

La presentacion debe sentirse premium y editorial, no como una lista comercial generica.

### 6. Process

Objetivo: generar confianza.

Contenido recomendado:

- Discovery.
- Concept.
- Design development.
- Visualization.
- Documentation.
- Delivery.

Puede resolverse con una animacion de scroll sutil o un layout tipo timeline.

### 7. Material / Atmosphere Section

Objetivo: sumar storytelling visual.

Contenido recomendado:

- Seccion inmersiva con imagen, textura, luz, masa o 3D.
- Frase conceptual.
- Funcion como puente emocional entre proyectos y servicios.

Este tipo de seccion ayuda a diferenciar la landing y reforzar la identidad visual.

### 8. About / Studio

Objetivo: humanizar la marca.

Contenido recomendado:

- Breve historia del estudio.
- Filosofia.
- Equipo o fundador si existe.
- Foto sobria o retrato editorial.
- Valores de diseno.

### 9. Testimonials / Recognition

Objetivo: aportar credibilidad.

Contenido recomendado:

- Frases de clientes.
- Premios.
- Publicaciones.
- Metricas sobrias: proyectos, anos, ciudades o clientes.

Si todavia no hay material real, puede omitirse en una primera version.

### 10. Contact / Inquiry

Objetivo: conversion.

Contenido recomendado:

- CTA claro.
- Email.
- Ubicacion.
- Redes.
- Formulario breve:
  - Nombre.
  - Email.
  - Tipo de proyecto.
  - Mensaje.

Debe ser elegante, directo y simple.

## Paginas Recomendadas

Para una primera version portfolio profesional:

- `/`: home landing completa.
- `/projects`: listado de proyectos.
- `/projects/:slug`: detalle de proyecto.
- `/studio`: informacion del estudio.
- `/contact`: contacto o inquiry.

Para una primera etapa, tambien puede mantenerse todo dentro de `/` y preparar la arquitectura para crecer despues.

## Orden Ideal En La Home

1. Hero.
2. Studio Intro.
3. Featured Projects.
4. Material / Atmosphere visual section.
5. Services.
6. Process.
7. Studio / About.
8. Contact CTA.
9. Footer.

## Recomendacion Principal

Primero conviene construir una home muy solida y mobile-first. Despues, agregar paginas internas de proyectos.

En arquitectura, la calidad visual de los proyectos pesa mas que la cantidad de secciones. La prioridad deberia ser:

1. Hero excelente.
2. Proyectos destacados.
3. Buen storytelling visual.
4. Contacto claro.
